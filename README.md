## The line

> My smart fridge emailed me a diet plan, then ordered pizza at 2 a.m. — even the appliances have given up on me.

## How it works

`main.ts` (Node 22, standard library only) writes the line to
`/output/entry.txt` — one line, UTF-8, no trailing newline, well within the
200-character limit.

## Run it

```sh
node main.ts
```
